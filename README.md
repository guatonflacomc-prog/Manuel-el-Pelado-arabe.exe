# el-pelado-arabe.exe
Manuel el Pelado Árabe.exe es un juego de humor absurdo y estilo caricaturesco, que se encuentra en desarrollo. La idea principal es crear una experiencia divertida y caótica, con un tono muy específico. El juego se inspira en referencias visuales y personajes exagerados.

El proyecto está en una etapa inicial. Hay demos y pruebas que tratan de definir el estilo, la forma de jugar y la personalidad del juego. Algunas versiones iniciales se están creando en Scratch, pero el proyecto podría cambiar de motor y mejorar con el tiempo.

Este es un juego que se hizo con la intención de explorar ideas creativas, humor y un estilo visual muy diferente. La propuesta sigue evolucionando y se está construyendo paso a paso.
